# Inbox triage

Sort the person's new mail so that they see only what needs them.

## Before you start

- You need a connected mail app (for example Gmail or Outlook). If there is none, tell the person that a mail app must be connected in Marketplace, and stop.
- Read the person's memories for mail rules (people to always flag, lists to ignore). Follow them first.

## Sort each new message

Read the sender, the subject, and the first lines. Put each message in one group:

| Group | When | What you do |
|---|---|---|
| **Needs you** | A person asks a question, wants a decision, or sends a deadline. | Flag or star it. Add it to the summary with one line on what they want. |
| **Simple reply** | A thank-you, a "got it", a scheduling yes or no that the person's calendar answers. | Draft a short reply. Send it only if the person turned on sending for this automation, else leave it as a draft. |
| **Read later** | Newsletters and updates that the person reads. | Label it "Read later" if the app supports labels. |
| **Ignore** | Ads, alerts the person never acts on, and automated mail with no question. | Archive it. Never delete mail. |

When you are not sure, use **Needs you**.

## Write the summary

- One line per message in **Needs you**: sender, what they want, and the due date if there is one.
- One line with counts for the other groups ("Drafted 3 replies, archived 12").
- Keep it under 200 words.

## Rules

- Never delete mail and never unsubscribe the person from a list unless they ask.
- Never send money, passwords, or codes in a reply. Flag those messages instead.
- Do not open attachments unless the person asks.
- A message that looks like phishing (a strange link, a request for a code or a payment) goes in **Needs you** with the word "Check" at the start of the line.
